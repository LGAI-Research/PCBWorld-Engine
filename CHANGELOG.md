# Changelog

Release notes for the PCBWorld Engine, newest first. This is a separate program from the
PCBWorld environment, which pins one engine commit per environment release.

## v1.1.0 — 2026-09-01

### Added
- Optional build targets, now documented: `BUILD_CLI=1` builds `kicad-cli` and `BUILD_PCBNEW=1`
  the `pcbnew` kiface + Python module from the same pinned, patched 9.0.8 source
  (`build_rl/kicad/kicad-cli`, `build_rl/pcbnew`). OpenCASCADE from Homebrew or the active conda
  env is handed to CMake automatically (the kiface's STEP exporter needs it); a build-tree
  `kicad-cli` requires `KICAD_RUN_FROM_BUILD_DIR=1` to find its kiface, as the build script's
  output now explains.

### Changed
- Re-running `build_rl_router.sh` with unchanged sources is now a link-only no-op: the patch
  overlay preserves file mtimes instead of re-stamping ~40 sources on every run.
- `kicad-cli` and the `pcbnew` module are built from this repository's own pinned source (above),
  so nothing downstream needs a distribution KiCad or a container to prepare board data.
- `pcbnew_prep/` conversion scripts prefer the interpreter they are invoked with
  (`PYTHONPATH=build_rl/pcbnew python …`); the apt `dist-packages` path is a fallback, no longer
  forced to the front of `sys.path`. Output of the source-built module is verified byte-identical
  to the apt build's (DSN/ORP, environment-metadata lines aside).
- DRC: the per-type report cap (199 / 499 violations) is removed — `pcbnew/drc/drc_engine.cpp`
  joins the modified set — so violation counts on large boards are exact.
- Crash diagnostics are bundle-local: on a fatal signal `engine_server/crash_diag.py` (with the
  native helper `crashtrace.c`) writes the C++ backtrace and the Python stack to the crash-log
  directory; a clean exit leaves no file (previously an inline `faulthandler` hook).
- `build_rl_router.sh` places the build next to the embedding environment when the engine sits at
  `<env>/engine`, and inside the engine for a standalone checkout (`BUILD_DIR` / `VENV_DIR`
  override).
- A read-only view of every change against upstream KiCad: `docs/upstream-diff/<file>.diff`, one
  unified diff per modified file, generated by `tools/make_upstream_diff.sh` and proved by round
  trip (pristine upstream + diff == the full copy). The modified regions of `drc_engine.cpp` carry
  `PCBWorld-mod begin / end` markers.

### Fixed
- The connected-points query returned an empty set when asked at the centre of a thru-hole pad
  or via: the hit resolved to the HOLE item, whose parent is null. It now resolves to the owning
  pad / via (`pns_rl_router.cpp`).

### Notes
- Apart from `drc_engine.cpp` and `pns_rl_router.cpp`, every modified upstream file is
  byte-identical to 1.0.0.
